# Пиксель

Терминал Ядра и инструмент восстановления. Часть Ядра (OrenCode), главный
помощник проекта «Армагеддон»: поднять инфраструктуру, когда серверов нет.

## Установка — одна строка

```bash
curl -fsSL https://raw.githubusercontent.com/Archakovss/pixel/main/install.sh | bash
```

Установщик печатает шаги `[1/4]…[4/4]`: проверка node, файлы в `~/.pixel/app`,
конфиг, команда `pixel` в PATH. Если чего-то не хватает — скажет, чего именно,
и остановится, ничего не сломав.

Дальше:

```bash
echo 'КЛЮЧ' > ~/.pixel/provider.key && chmod 600 ~/.pixel/provider.key
pixel doctor            # чего не хватает на этой машине
pixel                   # терминал
pixel recover           # подъём Ядра по карточке
```

## Что умеет

- Терминал с инструментами (bash, файлы, поиск, MCP-коннекторы), нативными
  вызовами инструментов, персистом сессии и `/undo` для правок.
- Работает **без шлюза Ядра**: шлюз мёртв — идёт к провайдеру напрямую.
  Это принципиально: иначе он не поднял бы то, через что сам ходит.
- `doctor` / `status` / `recover`.

## Восстановление Ядра

```bash
pixel recover
# или напрямую:
recovery/restore.sh --apply --yes \
  --from s3://<bucket>/dr/<date> --passphrase-file ~/.pixel/dr.pass
```

`restore.sh` показывает прогресс и время, как установщик:

```
[1/6] Проверяю машину        ✓ 0 с
[2/6] Беру снимок            ✓ 1 с
[3/6] Восстанавливаю базу    ✓ 6 с
[4/6] Поднимаю код           ✓ 25 с
[5/6] Настраиваю сайт        ✓ 0 с
[6/6] Приёмка                ✓ 0 с
──────────── и т о г ────────────
всего: 32 с
```

Измерено на чистом Debian 13: от «пакеты стоят» до отвечающего Ядра — 32 секунды.
С установкой пакетов — около десяти минут.

По умолчанию — **сухой прогон**: печатает, что сделает, и ничего не трогает.
Разрушительное — только с `--yes`. Поверх живого Ядра — отказ.

## Документы

- `recovery/ARMAGEDDON-HUMAN.md` — пошагово для человека.
- `recovery/ARMAGEDDON-LLM.md` — регламент для агента (проверки, стоп-условия).
- `recovery/ARMAGEDDON.md` — карточка: что держать вне сервера.

## Конфиг

`~/.pixel/config.json`:

```json
{
  "mode": "auto",
  "gateway": { "url": "http://127.0.0.1:3212", "tokenFile": "~/.pixel/gateway.token" },
  "provider": { "baseUrl": "https://api.deepseek.com/anthropic",
                "model": "deepseek-v4-flash", "keyFile": "~/.pixel/provider.key" }
}
```

`mode`: `auto` — шлюз, при недоступности провайдер; `gateway` — только шлюз;
`direct` — только провайдер. Ключи только файлами (600), не в конфиге.

## Границы

Пиксель не хранит память Ядра и не заменяет панель. Он — руки: запустить,
поднять, проверить. Необратимое (удаление данных, публикация, смена секретов)
остаётся за человеком.
