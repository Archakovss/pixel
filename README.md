# Пиксель

Терминал Ядра и инструмент восстановления. Часть Ядра (OrenCode), главный помощник
проекта «Армагеддон»: поднять инфраструктуру, когда серверов нет.

## Что умеет

- Интерактивный терминал с инструментами (bash, файлы, поиск, MCP-коннекторы),
  нативными вызовами инструментов, персистом сессии и `/undo` для правок.
- Работает **без шлюза Ядра**: если шлюз мёртв, идёт к провайдеру напрямую.
  Это принципиально — иначе он не смог бы поднять то, через что сам ходит.
- `pixel doctor` — чего не хватает на машине.
- `pixel status` — состояние шлюза, движка, сессии.
- `pixel recover` — подъём по карточке восстановления.

## Установка

```bash
git clone git@github.com:Archakovss/pixel.git
cd pixel && ./install.sh
$EDITOR ~/.pixel/config.json      # шлюз и/или провайдер
echo 'КЛЮЧ' > ~/.pixel/provider.key && chmod 600 ~/.pixel/provider.key
pixel doctor
```

Нужен Node.js 20+ и python3 (обёртка читает конфиг). Больше ничего.

## Конфиг

`~/.pixel/config.json`:

```json
{
  "mode": "auto",
  "gateway": { "url": "http://127.0.0.1:3212", "tokenFile": "~/.pixel/gateway.token" },
  "provider": { "baseUrl": "https://api.deepseek.com/anthropic",
                "model": "deepseek-v4-flash", "keyFile": "~/.pixel/provider.key" }
}
```

`mode`: `auto` — шлюз, при его недоступности провайдер; `gateway` — только шлюз;
`direct` — только провайдер. Ключи и токены — **только в файлах**, не в конфиге.

## Восстановление

- `recovery/ARMAGEDDON-HUMAN.md` — пошагово для человека, без терминального жаргона.
- `recovery/ARMAGEDDON-LLM.md` — операционный регламент для агента: точные команды,
  проверки после каждого шага, условия остановки.
- `recovery/restore.sh` — идемпотентный подъём (по мере готовности этапов P2).

## Границы

Пиксель не хранит память Ядра и не заменяет панель. Он — руки: запустить, поднять,
проверить. Решения о необратимом (удаление данных, публикация, смена секретов)
остаются за человеком.
